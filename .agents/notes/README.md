# 决策记录规范

## 命名

`{{YYYY-MM-DD}}-{{主题}}.md`，一个决策一个文件。

## 什么时候写

不是事后补文档，是**动手之前写**。满足任一条就先写再动手：

- 有两个以上可行方案，选哪个都不明显错
- 改动会影响多个模块的契约
- 你预感三个月后会有人问"为什么不用 X"

## 模板

```markdown
# 决策：{{一句话主题}}（{{YYYY-MM-DD}}）

已实施 / 已否决：{{状态}}

## 问题
{{现象 + 触发条件}}

## 决策
- {{做法一}}
- {{做法二}}

## 替代方案
- {{方案A}}：{{为什么否决}}
- {{方案B}}：{{为什么否决}}

## 影响
{{改动后谁受益、哪些后续工作变简单}}
```

## 唯一硬性要求：必须写替代方案

只写"我决定这么做"的决策记录等于没写。价值全在"我为什么不那么做"——那才是不可从代码反推的信息。
